# Features

An inventory of every user-facing capability in the codebase, grouped by area. Each entry names the file and function that implements it and a status.

Status meanings:

- **finished**: implemented end to end, reachable from the UI, nothing missing in this repo.
- **partial**: implemented but incomplete in a way a user or operator would hit (a control that does not save, an owner setup step outside the repo, a filter that does not apply).
- **dead code**: exists in the schema or a module but nothing in the app reaches it.

Nothing here is described from the plan documents. Every row points at code.
